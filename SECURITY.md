# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Use GitHub's private vulnerability reporting:

<https://github.com/PhaerisWakfu/tangbao/security/advisories/new>

Include:

- what the issue is
- how to reproduce it
- the affected route or component
- whether any production data or credentials may have been exposed

Please do not include live passwords, tokens, or user data in the report.

## Supported versions

This is a small independently operated project. Security fixes are applied to
the current `main` branch.
